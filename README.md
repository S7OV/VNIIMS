# 🧠 Проект прототипа нейротехнологической поддержки на базе облачной LLM для ВНИИМС
Реализация нейросетевого консультанта на базе Yandex GPT Pro для обработки обращений граждан и работы с нормативной документацией.
Проект разрабатывался как часть стажировки в рамках программы Университета Искусственного Интеллекта.

## 🔗 Репозиторий GitHub

## 📁 Структура проекта
```
latest/
├── yagpt_bot.py         — Telegram-бот с интеграцией Yandex GPT
├── embedding_qa.py      — Модуль для создания эмбеддингов вопросов и ответов
├── embedding_bd.py      — Обработка документов и создание векторной базы знаний
├── fastapi/
│   ├── main.py          — FastAPI сервер
│   ├── answers.py       — Логика получения ответов от модели
│   └── ...              — Вспомогательные файлы
└── .env                 — Файл с секретами (не коммитится)
```
## 🔧 Технологии
```
Yandex GPT – генерация ответов
FAISS / Yandex Embedding API – работа с векторными представлениями текста
LangChain – цепочки запросов и обработка контекста
FastAPI – запуск REST API
Telegram Bot API – реализация телеграм-бота
Boto3 – работа с Yandex Object Storage
RecursiveCharacterTextSplitter – разделение текста на чанки
MarkdownHeaderTextSplitter – структурирование Markdown-файлов
```
## 🧪 Основные возможности
Ответы на вопросы пользователей с опорой на нормативно-правовую базу.
Генерация экспертных заключений с правовым анализом.
Поддержка нескольких источников данных: .docx, .xlsx, .txt.
Автоматическое добавление новых документов в базу знаний.
Интеграция с облачным хранилищем Yandex Cloud Storage.

## 🛠️ Как запустить проект локально
```
1. Клонируйте репозиторий:
git clone https://github.com/S7OV/VNIIMS.git 
cd VNIIMS/latest
2. Установите зависимости:
pip install -r requirements.txt
3. Создайте .env файл:
env
# Yandex Cloud
IAM_TOKEN=your_iam_token
OAuth_token=your_oauth_token
ID_FOLDER=b1gmbmom8qe6nho8em9o

# AWS S3 (Yandex Cloud Storage)
access_key=your_access_key
secret_key=your_secret_key
⚠️ Не пушьте .env в репозиторий! Добавьте его в .gitignore. 

4. Запустите бота:
python yagpt_bot.py
5. Или запустите FastAPI:
uvicorn fastapi.main:app --reload
```
